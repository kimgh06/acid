# 보고서 양식

정유·화학 공정 설계 문서 관행(설계 기준서 + 연구 보고서 + 시운전 검증)에
국가연구개발사업 연구개발보고서 구성과 공문서 표기 규칙을 더한 양식.

| 문서 | 파일 | 운영 |
|---|---|---|
| 설계 기준서 (BOD) | `reports/BOD.md` | 하나를 개정(Rev A, B, …)하며 유지 |
| 단계 보고서 (SR) | `reports/NNN-<slug>.md` | 단계마다 새로 작성, 발행 후 수정 금지 |

## 1. 공통 규칙

가. 매개변수 값은 `params.yaml` 이 원본이다. 보고서·BOD 는 값을 인용만 한다.
나. 수치는 그 단계에서 실제 실행한 `uv run main.py` / `test_balance.py` / `sensitivity.py` 출력만 쓴다.
다. 상태는 `초안` → `검토용` → `승인`. 승인 전 기술 검토자 1인 확인.
라. 수율·회수율은 기준을 밝힌다 (기본: 원료 미강 중 총인 대비).
마. 표기 (「행정업무의 운영 및 혁신에 관한 규정 시행규칙」 제2조 준용)
  1) 날짜: `2026. 11. 16.` — 숫자, 연·월·일 뒤 온점
  2) 항목 기호: `1.` → `가.` → `1)` → `가)` → `(1)` → `(가)` → `①` → `㉮`
  3) 본문 끝에 `끝.` 표시
  4) 단위는 SI, 숫자와 단위 사이 한 칸 (`34.3 kg/h`)
바. 결론을 먼저 쓴다 (두괄식). 요약은 결론 3줄 + 핵심 지표 표.

## 2. 국가연구개발사업 보고서와의 대응

단계 보고서를 모아 최종 연구개발보고서(국가연구개발혁신법 시행규칙 서식: 표지 · 요약서 · 목차 · 본문 · 참고문헌)를 만들 수 있도록 절을 맞춘다.
장 제목은 시행규칙 별지 서식 원문으로 확인 후 맞춘다.

| 연구개발보고서 | 가져올 곳 |
|---|---|
| 요약서 | 최신 SR 1절 요약 + `reports/README.md` 단계 표 |
| 연구개발과제의 개요 (목적·필요성·범위) | `todo.md` 1절, BOD 1절 |
| 수행 내용 | 각 SR 3~6절 (기준·공정·수지·유틸리티) |
| 수행 결과 및 목표 달성도 | 각 SR 7절 검증, 8절 목표 달성도 |
| 성과 활용 계획 | 각 SR 9절 결론 및 권고 |
| 참고문헌 | 각 SR 10절 통합 |

## 7. 단위공정 구성     — 공정 순서와 각 단위공정 모델
## 8. 수지 허용오차     — 질량·P 원소수지 상대오차 기준
