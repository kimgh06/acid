## 1. 목적·범위

가. 목적: 폐농산물(미강)에서 인을 추출해 인산(H3PO4)으로 전환·정제하는 공정을 계산하는 시뮬레이션의 설계 기준을 정한다 (`todo.md` 1절).
나. 공정 범위(Battery Limit): 원료 미강 투입 ~ 제품 인산(농축 후) 배출.
다. 범위 밖: 경제성, 장치 비용·사이징, 폐기물(잔사·여액·석고) 처리, 제품 저장·출하.

## 2. 원료 사양

가. 원료
  1) 기준: 전지 미강(쌀겨) — `params.yaml` `feed`
  2) 대체: 탈지미강 — `params.yaml` `feedstocks.defatted_rice_bran` (`run(feedstock=...)`)
나. 조성 항목 (값은 `params.yaml` `feed`, 근거는 각 항목 `ref`):
  1) 수분 (습량 기준)
  2) 총인, 피트산 인 비율 (건량 기준)
  3) 단백질, 지질, 탄수화물 (건량 기준)
  4) K, Mg (건량) 와 추출 시 용출 분율 — 용출분은 용존 성분으로 추적
  5) 회분(인 외 무기질, 불용 K·Mg 포함) = 건량 − 위 성분 합
다. 피트산 인은 피트산(C6H18O24P6), 무기인은 H3PO4 로 표현한다.

## 3. 제품 사양

가. 농도: 75 wt% H3PO4 (≈ 54 % P2O5, 상품급) — `params.yaml` `concentration.target_wt`.
나. 순도 기준: 미정. 용도(비료·공업·식품 등급) 결정 후 불순물(H2SO4, IP1, K, Mg 등) 한도를 정한다.

## 4. 기준 조건

가. 처리량: 미강 1000 kg/h (가정, 결과는 비율로 해석).
나. 운전 형태: 연속 정상상태.
다. 원료·약품 투입 온도: 25 °C.
라. 엔탈피 기준: 25 °C, 1 atm, 생성열 포함 (BioSTEAM `Hnet`).

## 5. 물성·모델 기준

가. 시뮬레이터: BioSTEAM 2.54.0 / thermosteam (Python 3.12, uv).
나. 열역학: 이상용액. 전해질·이온 평형·pH 계산 없음 (pH 는 입력값).
다. 상 고정 물질
  1) 고상: Ca(OH)2, Ca3(PO4)2, CaSO4, 단백질·지질·탄수화물·회분 대체물질
  2) 액상(비휘발): 피트산, IP1, H3PO4, H2SO4, 효소 — 증발기에서 물만 증발
라. 대체물질 (DB 미등재 또는 물성 대용, `species.py`)
| 물질 | 물성 대용 | 비고 |
|---|---|---|
| Protein, Carbohydrate | Cellulose | 인 수지 무관 |
| Lipid | Triolein | |
| Ash | SiO2 | 인 외 무기질 |
| Phytase | Glucose | 수용성 효소 |
| K_ion, Mg_ion | Glucose | 화학식 K, Mg — 용존 금속 질량 추적 |
| IP1 (이노시톨 일인산) | myo-inositol | 화학식 C6H13O9P 로 교체 |
| Inositol | myo-inositol (DB) | 2차 효소 생성물 |
마. 반응
  1) 효소 가수분해: 피트산 + 5 H2O → IP1 + 5 H3PO4 (피타아제는 IP1 에서 멈춤)
     선택: IP1 + H2O → 이노시톨 + H3PO4 (산성 포스파타아제, 기준 미사용, 반응열 0)
  2) 침전: 2 H3PO4 + 3 Ca(OH)2 → Ca3(PO4)2 + 6 H2O
  3) 산 전환: Ca3(PO4)2 + 3 H2SO4 → 2 H3PO4 + 3 CaSO4, 잔류 Ca(OH)2 + H2SO4 → CaSO4 + 2 H2O
바. 반응열 보정: DB 의 피트산 생성열(+9004 kJ/mol)은 기여법 오류값 → 가수분해 반응열 0 이 되도록 피트산·IP1 생성열 설정 (가정). 대체물질 생성열 0.
사. 효소 전환율 모델: `params.yaml` `enzyme` 주석 (동역학·효소용량 중 작은 값, 55 °C 초과 열실활).
아. 침전 평형: PHREEQC 1.1.1, `minteq.v4.dat`, Davies 활동도 (`equilibrium.py`). P 침전 전환율은 문헌값(검증만), Mg 공침 분율은 PHREEQC 로 공정 계산에 사용. 침전 운전 pH 8.0–8.5 (pH ≥ 9 브루사이트 공침).

## 7. 단위공정 구성

| 단위공정 | 모델 | 주요 기준 (`params.yaml`) |
|---|---|---|
| SP1 / MX0 여액 재순환 | 분기기·혼합기, 여액 일부 → R1, 신규 공정수 = 목표 − 재순환 물 (기준 0) | `filtrate_recycle` |
| HX1 공정수 예열 | 향류 열교환기 (HXprocess), 퍼지 여액 → 신규 공정수, 재순환 | `heat_recovery` |
| R1 효소 추출 | 등온 반응조 (Tank), 피타아제 → (선택) 포스파타아제 직렬 반응 | `enzyme`, `phosphatase`, `pretreatment.water_ratio` |
| S1 고액분리 | 분배 분리기 (Separator) — 케이크 함액에 용존성분 동반 | `separation1` |
| R2 석회 침전 | 등온 반응조, 석회 = Ca/P 몰비 × 추출액 H3PO4 | `precipitation` |
| S2 Ca-인산 여과 | 분배 분리기 | `precipitation.cake_moisture` |
| R3 황산 전환 | 등온 반응조, 황산 = 과잉률 × (3 TCP + Ca(OH)2) | `acidulation` |
| S3 석고 여과 | 분배 분리기 | `acidulation.cake_moisture` |
| W1 석고 세척 | 함액 용질 회수율 모델 (Washer), 출구는 단열 혼합온도, 세척액은 농축으로 | `acidulation.wash_*` |
| E1 농축 | 단효용 진공 증발기, 목표 농도로 증발량 결정 | `concentration` |

## 8. 수지 허용오차

가. 단위공정마다 전체 질량과 P 원소 유량의 입·출 상대오차 ≤ 1×10⁻⁶ (`process.check_balance`).
나. 에너지: |Σ 입구 Hnet + Σ 유틸리티 unit_duty − Σ 출구 Hnet| ≤ 1 kJ/h (절대값, 생성열 포함). 유틸리티 소비량 보고는 전달효율 손실을 포함한 duty 를 쓴다.
다. 재순환 수렴 허용오차는 위 기준보다 엄격하게 둔다 (mol 1e-9, rmol 1e-10).
라. 초과 시 `BalanceError` 로 계산 중단. 허용오차를 키워 맞추지 않는다.
마. 각 반응식은 계산 전 원소수지 검사 (`Reaction.check_atomic_balance`).
