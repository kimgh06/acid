## 1. 요약

가. 결론
  1) 매개변수 24개를 문헌값으로 교체하고 문헌과 어긋나는 모델 구조 4가지를 고쳤다. P 회수율 0.419 → 0.670.
  2) 개선의 대부분은 석고 세척이다 (세척 제외 시 0.429).
  3) 산 전환 회수율·물 증발 스팀은 문헌 범위 내, 증발기 입구 농도·P2O5 당 스팀은 벗어난다 (Ca-인산 케이크 함수 희석).

## 4. 공정 설명

가. 공정 순서: R1 → S1 → R2 → S2 → R3 → S3 → **W1 석고 세척** → **M1 (여과산 + 세척액)** → E1 단효용 농축
나. 세척액은 반응기로 재순환하지 않고 농축으로 보낸다 (정상상태에서 물 부하는 같음).
